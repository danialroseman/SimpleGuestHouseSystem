# SimpleGuestHouseSystem

The project is a simple guest house reservation system implemented in Java. The system allows users to add, remove, and list reservations for a guest house with several houses.

There will be 2 main modules for the system. Which is an admin module and customers module. The admin module is used by the admins to add, remove, update all the houses. Admins also should be able to approve the bookings, and view the booking history. The customer module will allow the user to view the available houses, make their booking and view their bookings.
